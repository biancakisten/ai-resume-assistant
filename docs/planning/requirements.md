# Software Requirements

## Project Name

AI Resume Assistant

---

# Purpose

The AI Resume Assistant helps job seekers improve their resumes and prepare for job applications using artificial intelligence.

Users can upload a resume, paste a job description, and receive personalized AI feedback.

---

# Objectives

The system shall:

- Analyze resumes
- Compare resumes against job descriptions
- Generate tailored cover letters
- Suggest resume improvements
- Identify missing skills
- Generate interview questions
- Provide an ATS compatibility score

---

# Functional Requirements

## User Management

The system shall allow users to:

- Register an account
- Log in
- Log out
- Reset their password
- Update their profile

---

## Resume Management

Users shall be able to:

- Upload resumes
- Replace resumes
- Delete resumes
- View uploaded resumes
- Download resumes

Supported formats:

- PDF
- DOCX

Maximum upload size:

10MB

---

## Job Description

Users shall be able to:

- Paste a job description
- Save job descriptions
- Edit job descriptions
- Delete job descriptions

---

## AI Analysis

The AI shall:

- Analyze resume quality
- Compare resume against job description
- Suggest improvements
- Detect missing keywords
- Generate ATS score
- Recommend skills
- Recommend certifications
- Highlight strengths
- Highlight weaknesses

---

## Cover Letter Generator

The AI shall generate:

- Professional cover letter
- Company-specific cover letter
- Short version
- Long version

Users shall be able to copy the generated content.

---

## Interview Preparation

The AI shall generate:

- Technical interview questions
- Behavioural interview questions
- HR interview questions
- Suggested answers

---

## Dashboard

The dashboard shall display:

- Resume score
- ATS score
- Previous analyses
- Recent cover letters
- Saved job descriptions

---

# Non-Functional Requirements

The application shall:

- Load quickly
- Be mobile responsive
- Be secure
- Protect user data
- Support modern browsers
- Have an intuitive interface
